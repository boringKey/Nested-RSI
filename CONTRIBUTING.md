# Contributing

Focused bug fixes, reproducible examples, and evaluation discussions are welcome.

1. Open an issue for substantial interface or protocol changes.
2. Install with `python -m pip install -e .` in a virtual environment.
3. Run `python -m unittest discover -s tests -v` and `triad-rsi-demo`.
4. Explain changed behavior, evidence, and evaluation assumptions in the pull request.

Keep runtime dependencies minimal. Preserve exact task pairing and explicit error handling. Label synthetic examples. Do not submit credentials, private addresses, weights, task answers, or raw private logs. A higher selected score alone does not establish a better protocol.

Contributions are provided under the repository's MIT license.
