# Triad-RSI：三元协同自改进

研究数据（Data）、执行框架（Harness）与模型（Model）如何在同一个反馈循环中协同改进，并探索系统如何根据实验经验更新自身的提案规则与调度策略。

**当前发布：v1 / 0.1.0，核心代码预览。项目持续更新中。**

## 本次开放

- 成本感知的 softmax-UCB 算子选择。
- 算子资格、覆盖与尝试次数平衡约束。
- 当前状态与候选的配对接收判定。
- 默认每侧三轮、逐任务多数判定的确认评估。
- JSON 决策记录、离线示例与测试。

这些模块从现有研究原型提取和整理。完整训练服务、数据生成提示、模型权重、原始数据及规则更新实验暂未发布。

## 快速运行

Python 3.10+，在仓库根目录执行：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install .
triad-rsi-demo --output artifacts/demo
python -m unittest discover -s tests -v
```

示例无需 API key 或 GPU，使用固定合成结果演示调度、重复评估与接受/拒绝，不调用真实模型、不训练，也不代表 benchmark 成绩或持续学习效果。
