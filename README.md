# Triad-RSI

**Studying recursive self-improvement across data, harnesses, and models.**

Triad-RSI aims to build an open research framework for improving AI agent systems through three connected components:

- **Data:** collect verified trajectories and generate targeted training examples from execution feedback.
- **Harness:** improve prompts, workflows, tool-use guidance, and execution strategies.
- **Model:** update model parameters and training configurations using validated experience.

The project explores how these components can improve together, and how the system can revise its own proposal rules and scheduling strategies to make subsequent improvement cycles more effective.

Our focus is on reproducible experiments, controlled comparisons, and held-out evaluation of accepted changes.

**Status:** Early-stage research. This repository currently introduces the project; code and experiment documentation are being prepared for release.
